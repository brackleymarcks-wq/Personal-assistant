# Правила работы с агентом (Antigravity Bot)

## 1. Правила деплоя на Amvera
- **КОД:** Если мы внесли изменения в код и сделали git push, сервер автоматически НЕ пересобирает проект! После пуша обязательно нужно зайти в интерфейс Amvera и нажать кнопку **Пересобрать проект** (иконка кубика, слева от стрелочек). Без этого код не обновится!
- **ПЕРЕМЕННЫЕ:** Если мы меняем ТОЛЬКО переменные окружения, пересобирать код не нужно. Достаточно нажать **Перезапустить проект** (иконка круговых стрелочек).

## 2. Модели и Провайдеры (Текущий Стек)
- **Основной мозг (Генерация текста):** Бот работает на **GPT-4o** от Microsoft через бесплатные ключи GitHub Models.
  - AI_API_URL: https://models.inference.ai.azure.com/chat/completions
  - AI_MODEL: gpt-4o
  - AI_API_KEY: Токен начинается на github_pat_...
- **Голосовые сообщения (Распознавание):** Для аудио жестко прописано использование API **Groq (Whisper-large-v3)**.
  - Используется переменная GROQ_API_KEY (gsk_...).

## 3. Git
- Команда для пуша всегда: git push -f amverun main:master.
